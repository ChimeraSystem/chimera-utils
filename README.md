# Chimera Utilities

Command-line utilities and platform adapters for Chimera OS.

Repository: https://github.com/ChimeraSystem/chimera-utils

This component is currently built through the
[Chimera integration workspace](https://github.com/ChimeraSystem/chimera).
Its source checkout belongs at `coreutils/` in that workspace. Build recipes
still share the workspace toolchain and SDK; this is not a standalone build.
Existing copyright notices and bundled licenses apply to the imported files.
